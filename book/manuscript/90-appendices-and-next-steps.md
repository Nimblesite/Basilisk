# Appendices and next steps

> **Outline edition:** The reference appendices are generated or verified from
> the pinned release. They are not handwritten inventories that can silently
> drift.

## Appendix A — Command and configuration quick reference

Generate the command tree and flags from captured release help. Summarize the
configuration schema from the implementation and tests, with links into the
live [Basilisk configuration guide](https://www.basilisk-python.dev/docs/configuration/).

## Appendix B — Python typing vocabulary

Define annotation, assignability, subtyping, inference, narrowing, union,
protocol, type parameter, overload, stub, typeshed, and `Any`. Link every term
to the [Python typing specification](https://typing.python.org/en/latest/spec/index.html)
rather than inventing a parallel normative glossary.

## Appendix C — Source map

Map each book topic to the maintained typing specification, Python
documentation, CPython source, typeshed, packaging specification, and live
Basilisk destination. Explain when a PEP is historical context rather than the
current specification.

## Appendix D — Reproducibility record

Record the book revision, build date, Python interpreter used for the examples,
Basilisk release and source commit, the typeshed commit the examples were
captured against and whether it was pinned or the resolved latest,
upstream conformance snapshot, example results, screenshot environment,
image manifest result, link-audit result, Pandoc version, and EPUBCheck version.
