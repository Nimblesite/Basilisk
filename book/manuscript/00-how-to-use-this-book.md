# How to use this book

> **Outline edition:** This file records the intended front matter. It will be
> replaced by finished prose after the Basilisk release for this edition is
> pinned and the examples are executable.

This book is for Python developers who want to understand Basilisk rather than
merely make its messages disappear. You should be comfortable with ordinary
functions, classes, collections, imports, and tests. You do not need prior
experience with static typing.

## The promise

Reading cover to cover should take you from one deliberately incompatible
function call to a repeatable project workflow. You will learn enough Python
typing to predict common diagnostics, enough Basilisk configuration to express
your repository's policy, and enough editor and runtime tooling to connect
static feedback with tests, debugging, and profiling.

## Follow the Signal Box project

Each chapter advances the same small telemetry application. Run the checkpoint,
predict what Basilisk will say, make the change, and run it again. The examples
remain useful when typed by hand; copying the final code skips the most valuable
part of the exercise.

## Version and evidence conventions

The finished front matter will record the exact Basilisk release, Python 3.12
target, editor, operating system, example revision, and screenshot environment.
Python typing claims link to the maintained typing specification or Python's
own documentation. Basilisk behavior is tested against the release described by
the edition.

The [Basilisk website](https://www.basilisk-python.dev/) is the book's live
companion. Use it for installation changes, current rules, release notes, and
corrections after this fixed edition has been published.

## Visual conventions

Real screenshots show what the product did. Diagrams explain a relationship.
An orange path marks the current focus; a blue path marks Python information;
shape and labels repeat every color distinction. Captions explain why a figure
matters, and alt text carries the lesson for readers who cannot see it.
